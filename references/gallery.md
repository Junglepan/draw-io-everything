# 公开画廊的选择与适配

需要公开可编辑示例或缺少个人模板时按此表检索。示例均为虚构内容；使用前替换事实并核对关系。不要将画廊直接导入为个人默认或已验证的个人资产。

| 类型 | 源文件 | 可复用重点 |
| --- | --- | --- |
| 流程图 | [源文件](../examples/01-flow.drawio) | 主方向、条件标签与分支汇合 |
| 泳道图 | [源文件](../examples/02-swimlane.drawio) | 责任分区与阶段对齐；非完整 BPMN 范例 |
| 部署架构图 | [源文件](../examples/03-cloud.drawio) | 网络边界、服务分区与重复实例 |
| 集群组件图 | [源文件](../examples/04-cluster.drawio) | 控制面、工作节点与同构布局 |
| 时序图 | [源文件](../examples/05-sequence.drawio) | 参与者列、阶段与消息方向 |
| 系统上下文图 | [源文件](../examples/06-context.drawio) | 同一抽象层级与关系说明 |
| 应用资产图 | [源文件](../examples/07-application.drawio) | 位置表达归属，颜色与符号表达状态 |
| 数据血缘图 | [源文件](../examples/08-lineage.drawio) | 局部展开与关注路径 |
| 网络拓扑图 | [源文件](../examples/09-network.drawio) | 区域、接入与共享骨干 |
| 业务能力图 | [源文件](../examples/10-capability.drawio) | 层级网格与独立说明区 |
| 数据流水线图 | [源文件](../examples/11-pipeline.drawio) | 输入、处理、输出三段式 |

内容增长时先扩展组间距离、区域或拆分视图，保留同层节奏，不靠整体缩小字号。静态示例不模拟筛选、悬停或折叠交互。示例采用统一浅底以便 README 阅读；这不是要求用户所有图种共用同一风格。
